## Conteúdo

- 45 clips em português brasileiro: 265–270, 280–288, 291–300, 312–321 e 329–338.
- Ajuste individual de volume com o RMS do áudio original como referência.
- Formato PCM mono, 22.050 Hz, 8 bits.
- Tamanho preservado: 16.634.862 bytes; 376 blocos RIFF/WAVE identificados.

## Instalação rápida

1. Feche o jogo e o CorsixTH.
2. Localize o `SOUND-0.DAT` usado pela instalação do Theme Hospital.
3. Faça uma cópia de segurança, por exemplo `SOUND-0_original_backup.DAT`.
4. Baixe `SOUND-0_PTBR_V7.DAT` desta pasta.
5. Copie o arquivo baixado para a pasta onde está o original.
6. Renomeie o original para `SOUND-0_original_backup.DAT`, caso ainda não tenha feito isso.
7. Renomeie o arquivo baixado para `SOUND-0.DAT`.
8. Inicie o CorsixTH.

**Não apague o backup.** Para restaurar, feche o jogo, remova ou renomeie o arquivo V7 e renomeie o backup para `SOUND-0.DAT`.

Consulte o [guia completo de instalação](../../docs/instalacao.md).

## Limitações conhecidas

- A dublagem é parcial: 45 clips de 376 blocos identificados.
- A voz sintetizada é publicada como está nesta beta.
- Ainda não há simulação de alto-falante/PA, chiado ou estática. Esses efeitos e o refinamento da interpretação ficam planejados para versões futuras.
- A validação estrutural não substitui testes completos dentro do jogo.
- O ambiente de referência é Windows 10 + CorsixTH v0.70.1 Windows x64; outras configurações ainda precisam ser verificadas.
