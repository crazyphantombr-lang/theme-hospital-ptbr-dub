# Theme Hospital PT-BR --- Beta V7

A versão V7 disponibiliza o arquivo `SOUND-0_PTBR_V7.DAT` já compilado,
com 45 clips em português brasileiro incorporados.

## Download

-   **[Baixar SOUND-0_PTBR_V7.DAT](SOUND-0_PTBR_V7.DAT)**
-   [Abrir o arquivo no
    GitHub](https://github.com/crazyphantombr-lang/theme-hospital-ptbr-dub/blob/main/releases/v7/SOUND-0_PTBR_V7.DAT)
-   [Download
    direto](https://raw.githubusercontent.com/crazyphantombr-lang/theme-hospital-ptbr-dub/main/releases/v7/SOUND-0_PTBR_V7.DAT)

Não é necessário aplicar patch. O arquivo DAT já contém as substituições
de áudio da V7.

## Conteúdo

-   45 clips em português brasileiro: 265--270, 280--288, 291--300,
    312--321 e 329--338.
-   Ajuste individual de volume com o RMS do áudio original como
    referência.
-   Formato PCM mono, 22.050 Hz, 8 bits.
-   Tamanho preservado: 16.634.862 bytes; 376 blocos RIFF/WAVE
    identificados.

## Instalação

Consulte o [guia completo de instalação](../../docs/instalacao.md). Faça
backup do `SOUND-0.DAT` original antes de substituí-lo.

## Amostras de áudio

As amostras demonstrativas desta versão ficam em
[`samples/v7/`](../../samples/v7/). São arquivos MP3 para audição e não
devem ser usados no jogo.

## Limitações conhecidas

-   A dublagem é parcial: 45 clips de 376 blocos identificados.
-   A voz sintetizada é publicada como está nesta beta.
-   Ainda não há simulação de alto-falante/PA, chiado ou estática. Esses
    efeitos e o refinamento da interpretação ficam planejados para
    versões futuras.
-   A validação estrutural não substitui testes completos dentro do
    jogo.
-   O ambiente de referência é Windows 10 + CorsixTH v0.70.1 Windows
    x64; outras configurações ainda precisam ser verificadas.

## Aviso

Theme Hospital pertence aos seus respectivos titulares. Este é um
projeto independente e não oficial.
